# Focus Zoom for Premiere Pro

画面録画の小さな文字やボタンに、すっと寄る。Focus Zoomは、プレビューの緑枠で見せたい範囲を囲むだけで、Premiere Proに滑らかなズームや移動を作れるプラグインです。

## ダウンロード

[0.5.1 プレビュー版](https://github.com/onihachi/focus-zoom/releases/tag/v0.5.1) の **Assets** から `Focus-Zoom-0.5.1-preview.zip` をダウンロードしてください。GitHubの自動生成ファイル「Source code (zip)」ではありません。

- 対象：Premiere Pro 26.5以降、Adobe Creative Cloudデスクトップアプリ。
- **プレビュー版**：自動テスト済みですが、この配布版の新規インストールと動作はPremiere実機では未検証です。まずは本番ではなく、短いテスト用クリップでお試しください。

## インストール

1. 配布ZIPを解凍し、中の `Focus-Zoom-0.5.1.ccx` をダブルクリック。
2. Creative Cloudで配布元を確認し、インストール。Marketplace外のプラグインとして確認画面が出る場合があります。
3. Premiere Proを開き、**ウィンドウ → UXPプラグイン → Focus Zoom**。表示されなければ、保存してからPremiereを開き直します。

開発者モードやUXP Developer Toolは不要です。[Adobe公式手順](https://developer.adobe.com/premiere-pro/uxp/plugins/distribution/install/)

## 使い方

1. タイムラインの映像クリップを1つ選ぶと、プレビューが自動で表示されます。
2. 再生ヘッドをクリップ内に置きます。緑枠の内側をドラッグして位置、辺や角で範囲を調整して **移動** を押します。
3. 元素材の全体を見せたい位置で **全体へ戻す**。以前の倍率に戻すのではなく、素材の端まで入るように中央へ合わせます。

ウィンドウの横幅にプレビューが追従します。映像を取り出せない位置では、可能な場合だけ **映る位置へ** が出ます。押すと再生ヘッドだけ動き、ズームのキーは追加しません。映る位置がない場合は、Premiereの **エフェクトコントロール → モーション** で位置・スケールを調整できます。

## 注意点

- 初回プレビューで `FocusZoom-Overview-` から始まる補助シーケンスを作ります。選択だけでは編集タイムラインにキーを追加しません。
- 「移動」「全体へ戻す」はクリップの **モーション** に約0.6秒のキーを追加します。既存キーと重なる場合は上書きせず止まります。操作はPremiereの取り消しで戻せます。
- 逆再生・タイムリマップ・フレーム保持は、先にネストして外側を選んでください。

Adobe非公式のプラグインです。
